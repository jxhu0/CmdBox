# CmdBox 官网实施计划

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- []`) syntax for tracking.

**Goal:** 创建 CmdBox 产品官网（单页 Landing Page），部署到 GitHub Pages，支持中英双语。

**Architecture:** 纯静态 HTML/CSS/JS 单文件 `index.html`，无框架依赖。通过 `data-lang` 属性和 JS 实现中英双语切换。GitHub Pages 从仓库根目录或 `gh-pages` 分支部署。

**Tech Stack:** HTML5, CSS3 (Grid/Flexbox), Vanilla JS, Google Fonts (Space Grotesk, DM Sans, JetBrains Mono)

---

## Chunk 1: 创建网站文件

### Task 1: 创建 index.html 主文件

**Files:**
- Create: `index.html`

- [ ] **Step 1: 创建 index.html，包含完整页面结构和样式**

基于已确认的设计方案（`design-v3-polished.html`），创建 `index.html`。包含以下区域：
- 浮动导航栏（毛玻璃效果，Logo + 链接 + GitHub + 下载按钮 + 语言切换）
- Hero 区域（徽章、渐变标题、副标题、双 CTA）
- 数据条（4 项关键指标）
- 应用模拟截图（仿 macOS 窗口，悬浮动画）
- 功能亮点（6 卡片 3 列网格）
- Git 同步展示（左文右图）
- 快速上手（3 步时间轴）
- 下载 CTA（双平台按钮）
- 页脚

所有文案元素使用 `data-lang-zh` / `data-lang-en` 属性标记。

关键设计规格：
- 背景色 `#07090F`，固定点阵网格 + 双色径向光晕
- 字体：Space Grotesk（标题）、DM Sans（正文）、JetBrains Mono（代码）
- 全部内联 SVG 图标，不使用 emoji
- 导航栏 `position: fixed; top: 16px; border-radius: 14px;`
- 模拟截图 `animation: float 6s ease-in-out infinite`
- 功能卡片 hover 顶部辉光（`--card-glow` CSS 变量）
- 滚动渐入动画（Intersection Observer）

参考设计文件：`.superpowers/brainstorm/24054-1775578420/design-v3-polished.html`

- [ ] **Step 2: 实现中英双语切换**

在导航栏添加语言切换按钮（EN/中）。JS 实现逻辑：
- 默认中文
- 点击切换按钮遍历所有带 `data-lang-zh` / `data-lang-en` 的元素
- 切换 `textContent`
- 按钮文案在「EN」和「中」之间切换
- 语言偏好存入 `localStorage`

英文翻译覆盖所有可见文案（标题、描述、按钮、功能说明等）。

- [ ] **Step 3: 添加 `prefers-reduced-motion` 支持**

在 CSS 中添加：
```css
@media (prefers-reduced-motion: reduce) {
  .app-mockup { animation: none; }
  .animate-on-scroll { transition: none; opacity: 1; transform: none; }
  .hero-badge-dot { animation: none; }
}
```

- [ ] **Step 4: 在浏览器中验证页面**

在本地打开 `index.html`，验证：
- 所有区域正确渲染
- 导航锚点平滑滚动
- 滚动渐入动画正常
- 功能卡片 hover 效果
- 模拟截图悬浮动画
- 中英双语切换
- 响应式布局（375px / 768px / 1440px）
- `prefers-reduced-motion` 关闭动画

- [ ] **Step 5: 将 .superpowers/ 添加到 .gitignore**

确认 `.superpowers/` 已在 `.gitignore` 中（设计草稿不需要提交）。

## Chunk 2: 配置 GitHub Pages

### Task 2: 启用 GitHub Pages 部署

- [ ] **Step 1: 提交 index.html**

```bash
git add index.html
git commit -m "feat: 添加产品官网 Landing Page"
```

- [ ] **Step 2: 推送到远程**

```bash
git push origin main
```

- [ ] **Step 3: 启用 GitHub Pages**

通过 GitHub CLI 或网页操作：
```bash
gh api repos/jxhu0/CmdBox/pages -X POST -f build_type=workflow -f source[branch]=main -f source[path]="/"
```

或手动在 GitHub 仓库 Settings → Pages 中选择：
- Source: Deploy from a branch
- Branch: main, / (root)
- 保存

- [ ] **Step 4: 验证部署**

等待 1-2 分钟后访问 `https://jxhu0.github.io/CmdBox/`，确认页面正常加载。

- [ ] **Step 5: 清理设计草稿文件（可选）**

`.superpowers/brainstorm/` 下的设计草稿文件仅用于设计阶段，不影响最终网站。
