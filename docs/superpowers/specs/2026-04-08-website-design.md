# CmdBox 官网设计规格

## 概述

为 CmdBox 创建一个单页 Landing Page 产品官网，部署到 GitHub Pages，中英双语。

## 技术方案

- 纯静态 HTML/CSS/JS 单文件（无框架依赖）
- 部署到 GitHub Pages（`jxhu0.github.io/CmdBox`）
- 文件位置：仓库根目录 `index.html`

## 设计系统

### 配色

| 用途 | 颜色 |
|------|------|
| 背景 | `#07090F` |
| 文字主色 | `#F8FAFC` |
| 文字次色 | `#94A3B8` |
| 文字弱色 | `#475569` / `#334155` |
| 主色调 | `#3B82F6` (蓝) / `#6366F1` (靛) |
| 强调色 | `#60A5FA` / `#A78BFA` |
| 成功色 | `#22C55E` / `#4ADE80` |
| 边框 | `rgba(255,255,255,0.06)` |

### 字体

- 标题：Space Grotesk (700)
- 正文：DM Sans (400/500/700)
- 代码/命令：JetBrains Mono (400/500)

### 图标

- 全部使用内联 SVG（Heroicons 风格），不使用 emoji
- 统一 viewBox `0 0 24 24`，stroke-width 2

## 页面结构

1. **浮动导航栏** — 毛玻璃效果，Logo + 导航链接 + GitHub + 下载按钮
2. **Hero 区域** — 徽章（版本+开源）、主标题（渐变文字）、副标题、双 CTA 按钮
3. **数据条** — 4 项关键指标（免费/跨平台/Git 驱动/MIT）
4. **应用模拟截图** — 仿 macOS 窗口，含侧边栏、搜索栏、命令卡片，悬浮动画
5. **功能亮点** — 6 张功能卡片，3 列网格，每张含图标+标题+描述
6. **Git 同步展示** — 左文右图布局，功能要点 + 同步流程图
7. **快速上手** — 3 步引导，时间轴样式
8. **下载 CTA** — 卡片内嵌，macOS/Windows 双下载按钮
9. **页脚** — 版权 + 链接

## 交互与动效

- 滚动渐入动画（Intersection Observer，threshold 0.1）
- 功能卡片 hover：顶部辉光 + 微上移
- 模拟截图：6s 缓动悬浮动画
- 导航按钮 hover：背景色变化 + translateY
- 锚点平滑滚动
- `prefers-reduced-motion` 适配
- 响应式：375px / 768px / 1024px / 1440px

## 背景

- 固定点阵网格（40px 间距，3% 透明度白点）
- 双色径向光晕（左上蓝、右下紫）

## 中英双语

- 默认中文，提供语言切换按钮
- 切换方式：顶部导航栏的语言切换按钮，JS 动态切换 `data-lang` 属性
- 所有文案元素使用 `data-lang-zh` / `data-lang-en` 属性
