# CmdBox 设计文档

> 创建日期：2026-03-18

## 概述

CmdBox 是一款桌面应用，用于保存和管理常用的命令行指令（Linux Command）及大模型 Prompt（自然语言），支持跨设备 Git 同步。

## 技术栈

| 项目 | 选择 |
|------|------|
| 语言 | Python |
| UI 框架 | Flet |
| 数据存储 | JSON 文件 |
| 同步方式 | Git 仓库 |
| 剪贴板 | pyperclip |

### 依赖列表

```
flet>=0.21.0           # UI 框架
gitpython>=3.1.40      # Git 操作
pyperclip>=1.8.2       # 剪贴板操作
```

## 数据模型

### 文件结构

```
cmdbox-data/              # Git 仓库目录（用户指定）
├── config.json           # 应用配置
└── data.json             # 用户数据
```

### config.json

```json
{
  "repo_path": "/Users/xxx/cmdbox-data",
  "auto_commit": false,
  "theme": "light",
  "last_sync": "2026-03-18T10:00:00"
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| repo_path | string | Git 数据仓库的本地路径 |
| auto_commit | boolean | 是否自动提交（预留） |
| theme | string | 界面主题（light/dark） |
| last_sync | string | 上次同步时间（ISO 8601） |

### data.json

```json
{
  "boards": [
    {
      "id": "uuid-1",
      "name": "Linux Commands",
      "icon": "terminal",
      "created_at": "2026-03-18T10:00:00",
      "updated_at": "2026-03-18T10:00:00"
    }
  ],
  "commands": [
    {
      "id": "uuid-2",
      "board_id": "uuid-1",
      "title": "查找大文件",
      "content": "find . -type f -size +100M",
      "description": "查找当前目录下大于100M的文件",
      "tags": ["linux", "disk"],
      "is_favorite": false,
      "created_at": "2026-03-18T10:00:00",
      "updated_at": "2026-03-18T10:00:00"
    }
  ]
}
```

#### Board 字段

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | string | ✅ | 唯一标识（UUID） |
| name | string | ✅ | 板块名称 |
| icon | string | ❌ | emoji 或图标名称 |
| created_at | string | ✅ | 创建时间 |
| updated_at | string | ✅ | 更新时间 |

#### Command 字段

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | string | ✅ | 唯一标识（UUID） |
| board_id | string | ✅ | 所属板块 ID |
| title | string | ✅ | 指令标题 |
| content | string | ✅ | 指令内容 |
| description | string | ❌ | 详细描述 |
| tags | array | ❌ | 标签列表 |
| is_favorite | boolean | ✅ | 是否收藏 |
| created_at | string | ✅ | 创建时间 |
| updated_at | string | ✅ | 更新时间 |

## 界面设计

### 布局结构

```
┌─────────────────────────────────────────────────────────────┐
│  CmdBox                                    [同步] [设置]     │  ← 顶部栏
├────────────┬────────────────────────────────────────────────┤
│            │                                                │
│  板块列表   │              主内容区                          │
│            │                                                │
│  📁 Linux  │   ┌──────────────────────────────────────┐    │
│  Commands  │   │ 🔍 搜索...          [下拉: 全部板块 ▼] │    │  ← 搜索栏
│            │   └──────────────────────────────────────┘    │
│  📁 AI     │                                                │
│  Prompts   │   ┌────────────────────────────────────────┐  │
│            │   │ ⭐ 查找大文件                          │  │
│  ────────  │   │ find . -type f -size +100M             │  │  ← 指令卡片
│  + 新建板块 │   │ 🏷️ linux, disk    📋 复制  ✏️ 编辑     │  │
│            │   └────────────────────────────────────────┘  │
│            │                                                │
└────────────┴────────────────────────────────────────────────┘
```

### 区域说明

| 区域 | 功能 |
|------|------|
| 顶部栏 | 应用名称 + 同步按钮 + 设置入口 |
| 左侧栏 | 板块列表，点击切换；底部有「新建板块」按钮 |
| 搜索栏 | 实时过滤输入框 + 板块下拉选择器 |
| 主内容区 | 指令卡片列表，显示标题、内容预览、标签、操作按钮 |

### 交互设计

- **复制**：点击「📋」→ 复制 content 到剪贴板 → 显示「已复制」提示
- **查看详情**：点击卡片 → 展开显示完整 description + content
- **编辑后使用**：点击「✏️」→ 弹窗显示可编辑文本框 → 修改后点击「复制」
- **收藏的指令**：显示 ⭐ 图标，可置顶显示

## 核心功能

### 1. 板块管理

- 新建板块：弹窗输入名称和图标
- 编辑板块：修改名称和图标
- 删除板块：确认后删除板块及其下所有指令

### 2. 指令管理

#### 新建指令弹窗

```
┌─────────────────────────────────────────┐
│  新建指令                           [×]  │
├─────────────────────────────────────────┤
│  标题 *                                 │
│  ┌───────────────────────────────────┐  │
│  │                                   │  │
│  └───────────────────────────────────┘  │
│  所属板块 *                             │
│  ┌───────────────────────────────────┐  │
│  │                             [▼]  │  │
│  └───────────────────────────────────┘  │
│  指令内容 *                             │
│  ┌───────────────────────────────────┐  │
│  │                                   │  │
│  │                                   │  │
│  └───────────────────────────────────┘  │
│  描述（可选）                           │
│  ┌───────────────────────────────────┐  │
│  │                                   │  │
│  └───────────────────────────────────┘  │
│  标签（可选，逗号分隔）                  │
│  ┌───────────────────────────────────┐  │
│  │                                   │  │
│  └───────────────────────────────────┘  │
│  ☐ 添加到收藏                           │
│                                         │
│         [取消]        [保存]            │
└─────────────────────────────────────────┘
```

#### 编辑指令

与新建弹窗布局相同，预填充当前值，按钮改为「保存更改」。

### 3. 搜索功能

- **实时过滤**：输入即时过滤结果
- **搜索范围**：标题、内容、标签（均模糊匹配）
- **板块过滤**：下拉选择器可选择特定板块或全部

### 4. Git 同步

#### 同步流程

```
用户点击「同步」
      │
      ▼
检查 Git 仓库状态
      │
      ▼
有远程更改？──是──▶ Pull 远程更改
      │
      否
      │
      ▼
Commit 本地更改
      │
      ▼
Push 到远程
      │
      ▼
  ✅ 同步完成
```

#### 同步策略

- 手动触发，用户完全控制
- 先 Pull 再 Push，避免冲突
- 冲突时保留两份，让用户手动合并

## 首次启动流程

```
应用启动
    │
    ▼
检查 config.json 是否存在
    │
    ├── 存在 ──▶ 加载配置 ──▶ 启动应用
    │
    └── 不存在
          │
          ▼
     显示欢迎向导
          │
          ▼
     用户选择/创建 Git 仓库路径
          │
          ▼
     初始化 config.json
     初始化 data.json
          │
          ▼

          │
```

## 错误处理

| 场景 | 处理方式 |
|------|----------|
| Git 仓库路径无效 | 提示用户重新选择路径 |
| Git push/pull 失败 | 显示错误信息，建议检查网络或权限 |
| 数据文件损坏 | 尝试恢复备份，失败则提示重新初始化 |
| 剪贴板复制失败 | 显示错误提示，让用户手动复制 |
| 表单验证失败 | 字段下方显示红色错误提示 |

## 边界情况

| 场景 | 处理方式 |
|------|----------|
| 删除板块下有指令 | 弹窗警告，显示指令数量，确认后删除 |
| 搜索无结果 | 显示「暂无匹配结果」提示 |
| 板块列表为空 | 主内容区显示「请先创建板块」引导 |
| Git 仓库未初始化 | 首次同步时自动执行 `git init` |
| 远程仓库未配置 | 设置中提供配置 remote URL 的入口 |
