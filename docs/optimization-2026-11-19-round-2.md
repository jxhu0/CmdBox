# 第二轮代码分析与优化（2026-11-19）

本轮基线为 `7afae2f`。检查搜索任务调度、缓存生命周期、指令渲染、任务/问题排序、筛选状态、弹窗回调、备份清理和更新检查。环境为 macOS、Python 3.13、Flet 0.82.2。

## 已完成

| 方面 | 问题 | 改进 |
| --- | --- | --- |
| 后台计算 | 取消输入防抖不能停止已经开始的 `to_thread` 计算；快速回车或切换筛选时可能同时计算多个搜索 | 新增 `SearchRunner`，使用一个专用工作线程；取消尚未执行的旧请求，保留正在执行的请求和最新待执行请求；退出时清理队列 |
| 搜索缓存 | 每次查询用当前板块结果替换整个缓存，交替搜索板块反复规范化正文；没有容量限制 | 改为按最近使用淘汰的跨范围缓存；指令、任务、问题的估算容量分别限制在 128、16、32 MiB，临时候选缓存也受限；过大记录仍可搜索；加载时清空的缓存不会被旧计算重新填入 |
| 卡片刷新 | 指令卡片签名调用 `repr` 复制整段正文，渲染签名还需深复制 | 比较独立字段快照，正文直接保留不可变字符串引用，标签转成不可变元组；减少长正文处理和复制 |
| 交互边界 | UI 禁用不能挡住已送达的点击或已经打开的弹窗回调 | 为新建、编辑、删除及设置回调统一增加忙碌状态和数据加载代次检查；数据整体重载后旧弹窗不能继续提交；拒绝提交时保留编辑内容 |
| 恢复操作 | 异步恢复期间设置仍可关闭或再次点击，完成时可能关闭其他弹窗 | 恢复期间禁用设置和数据编辑；阻止重复恢复，失败后恢复交互；完成后只关闭对应设置窗口 |
| 备份安全 | `data_local_*.json` 与普通备份共用通配符，可能被十份轮转删除，或在损坏恢复时被静默选中 | 本地冲突副本不参与自动清理、自动恢复，仍可手动恢复；设置展示全部备份并区分来源，提示副本需手动清理 |
| 排序 | 同优先级任务按旧时间在前；按时间排序时执行中任务没有统一时间顺序 | 同优先级最新在前，执行中任务也按时间排序；问题排序用时间作为稳定的次级顺序 |
| 分页与空状态 | 翻页后仍留在旧页底部；无搜索结果被提示为“暂无数据” | 翻页和换排序回到顶部；区分空数据与筛选无结果，给出清空筛选提示；提取共用列表辅助组件 |
| 筛选一致性 | 删除最后一个标签后下拉框显示全部，应用仍保留已经失效的标签条件 | 同步清除界面与应用的失效条件，并取消旧请求，避免迟到结果重新带回旧条件 |
| 更新提示 | 重复初始化可能重复请求；关闭后仍可能弹出更新；版本缓存写入失败会中断通知 | 合并正在进行的检查；关闭或数据操作期间不弹出新提示；缓存写入失败仍可通知；修正可选配置字段的错误类型，长更新说明可以滚动 |

## 性能测量

以下为 Python 局部处理时间，不包含原生窗口完整渲染时间，不代表整体应用或启动速度。

```bash
python -m tests.benchmark_lists --baseline 7afae2f
python -m tests.benchmark_search
python -m tests.benchmark_interactions
```

| 场景 | 基线 | 本轮 |
| --- | ---: | ---: |
| 1,000 条长正文指令，更新当前页一条记录（9 次中位数，每条正文 3,000 组说明） | 1.92 ms | 0.14 ms |
| 在两个各含 1,000 条指令的查询范围之间交替搜索（预热后，14 次中位数） | 15.26 ms | 2.54 ms |
| 同一范围 10,000 条指令连续搜索（7 次中位数） | 30.94 ms | 32.06 ms |
| 同一范围 10,000 条指令首次搜索 | 167.82 ms | 174.72 ms |

长正文页刷新约减少 93%，跨范围搜索约减少 83%。单范围搜索新增容量管理有少量开销，本轮并未进一步加速这一场景。普通板块切换仍约为首次 22–23 ms、已访问 2.4–2.7 ms；这些差异不构成新的提速结论。

使用 1,000 条长正文、64 KiB 缓存预算做额外内存检查，缓存估算为 55.8 KiB，`tracemalloc` 记录的本次查询分配峰值约 125.7 KiB。缓存预算不是整个 Python 进程内存上限；模型、查询结果、映射开销及新旧计算的临时对象仍占用内存。超过缓存容量的数据集会出现更多重新计算。

## 仍值得推进

- `app.py` 的弹窗与 CRUD 编排仍较集中；本轮抽出了搜索调度和共用列表呈现，进一步拆分领域控制器应保持交互与数据操作边界。
- 普通 Git JSON 冲突继续安全中止，按记录的三方合并仍需独立设计删除、编辑与排序冲突的规则。
- 受限缓存改善常用范围复用，超大数据集仍为线性扫描；应以实际用户数据规模决定是否引入持久化索引。
- Windows 冷启动、原生文件选择器与整包运行表现仍需 Windows 实机测量，不能用 macOS 局部基准推断。
